# shell→python+postgreSQLの移行計画

## shell→python
### 各機能分類
#### VPS.ask.ct.sh
- 引数に挑戦数、IDを取る
- CSVファイルから指定数を取りだしてシャッフルし、ファイル書き込み
- ⇩While文
- ファイルから`,`区切りの英単語、意味を抜き出しそれぞれ変数に挿入
- 入力を受け取って変数に挿入
- 入力変数の文字数をチェック　0ならスキップ、１なら無効解答で再記入
- 解答変数内を入力変数で検索、正誤判断
- 正解なら１，不正解なら０をカウントファイルに記述S
- 繰り返し

### python構成計画
#### 全体の流れ
- DBから単語、idをそれぞれ取得  GET　　
- 取得した全ての単語を問題として表示
- 解答受付　　POST
- idと解答を紐づけ
- idで意味を検索
- 解答と意味を比較
- 正誤判断
- 正答数、率計算　　percentage.py
- 結果表示
- 終了
